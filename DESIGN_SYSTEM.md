# Hope, Inc. ERP - Design System (S1-UIX-01)

This document contains the core design tokens and components for the Login and Sign Up screens.

## 1. Colors 
Here are the exact hex codes used in the design:

**Text & Borders:**
*   **Main Text (White):** `#ffffff`
*   **Link/Border (Vivid Azure):** `#0d5da3`
*   **Link Hover (Dark Azure):** `#184169`

**Backgrounds & Shapes:**
*   **Main Background (Linear Gradient 180°):** `#0b0b0c` to `#040727`
*   **Form Header (Linear Gradient 90°):** `#0f3b62` to `#debcfF`

**Buttons:**
*   **Primary Button (Vivid Azure):** `#0d5da3`
*   **Secondary Button (Dark Azure Border):** `#184169`

**Error States (System & Input):**
*   **Vivid Red (Border):** `#ff0000`
*   **Coral Red (Background/Text):** `#ff5757`

## 2. Typography
*   **Font Family:** `Poppins, sans-serif` (or similar clean sans-serif)
*   **Headings (e.g., Form card, Buttons):** `24px`, `Bold` / `600`
*   **Body Text / Labels:** `14px`, `Regular` / `400`
*   **Small Text (Error messages, Notes):** `12px`, `Regular` / `400`

## 3. Core Components

*   **Form Card:** White container with a gradient header. Rounded corners.
*   **Text Boxes:** White background, pill-shaped (fully rounded), with gray outline. 
*   **Error Text Box:** Pink background with red border and red text. Includes a required message inside.
*   **Buttons:** 
    *   *Primary:* Solid Base Blue background with white text.
    *   *Secondary:* Transparent background, blue outline, and white/blue text.
*   **Error Messages:** 
    *   *System Error (Wi-Fi):* A pink alert box with red text inside the form card.
    *   *Input Error:* Red text below the text box.
*   **Links:** White texts text. On hover, a highlight or underline effect is applied (as noted in the design).
